# Code of Conduct

Open Glow follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, and keep discussions about the work.

Report unacceptable behavior to the maintainers by opening a private
[security advisory](../../security/advisories/new) or contacting them directly. Reports are
handled confidentially.
